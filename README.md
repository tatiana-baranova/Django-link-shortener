ShortLink — вебзастосунок для скорочення URL-адрес, створений на базі Django.

Користувач може зареєструватися, увійти до особистого кабінету, створювати короткі посилання та зберігати їх у своєму профілі.

Валідація пароля під час реєстрації
Особистий кабінет користувача
Перегляд та редагування username і email

Створення коротких посилань

Перевірка унікальності короткого коду

Встановлення та запуск
1. Клонування репозиторію
git clone <URL-репозиторію>
cd Django-link-shortener
2. Створення віртуального середовища
python -m venv .venv
3. Активація віртуального середовища

Для Windows PowerShell:

.venv\Scripts\Activate.ps1
4. Встановлення залежностей
pip install -r requirements.txt
5. Налаштування змінних середовища

Створіть файл .env у кореневій папці проєкту та додайте секретний ключ Django:

SECRET_KEY=your-secret-key

Також необхідно налаштувати підключення до PostgreSQL відповідно до параметрів локальної бази даних.

6. Застосування міграцій
python manage.py migrate
7. Створення адміністратора
python manage.py createsuperuser
8. Запуск сервера
python manage.py runserver

Після запуску застосунок буде доступний за адресою:

http://127.0.0.1:8000/


Робота з посиланнями

Користувач створює короткий код для оригінальної URL-адреси.

Наприклад:

Оригінальне посилання:
https://example.com/some/very/long/url/

Скорочений код:
example

Після створення користувач отримує коротке посилання:

http://127.0.0.1:8000/link/example/

При переході за ним користувач автоматично перенаправляється на оригінальну адресу.

База даних

Для зберігання даних використовується PostgreSQL.

Основна модель Link містить:

користувача, якому належить посилання;
оригінальну URL-адресу;
унікальний короткий код.

Для користувачів використовується стандартна модель User Django та додаткова модель Profile.

Безпека

Секретні налаштування проєкту зберігаються у файлі .env.

Файл .env не повинен завантажуватися до репозиторію. Для цього він доданий до .gitignore.
